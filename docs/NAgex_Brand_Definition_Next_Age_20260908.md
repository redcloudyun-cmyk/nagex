# NAgex Brand Definition
## Personal AI for the Next Age

**Brand:** NAgex  
**Category:** Personal AI  
**Brand Promise:** Intelligence for the Next Age.  
**Consumer Positioning:** NAgex — Personal AI for the Next Age  
**Internal Architecture:** NAgex Personal AI Operating System  

---

# 1. Brand Overview

NAgex는 단순한 AI Agent 플랫폼을 지향하지 않는다.

NAgex의 핵심은 사용자가 여러 Agent, Tool, Model, Plan을 직접 이해하고 선택하는 것이 아니라, 하나의 Personal AI에게 원하는 일을 자연스럽게 맡기는 경험이다.

NAgex가 표현하고자 하는 것은 다음과 같은 변화다.

```text
AI as a tool
↓
AI as an agent
↓
AI as a persistent personal intelligence
↓
NAgex
```

NAgex는 이 전환을 “Next Age”라는 브랜드 개념으로 표현한다.

즉 NAgex는 단순히 “다음 세대의 Agent”가 아니라, 새로운 AI 사용 방식으로 넘어가는 시대적 변화를 상징한다.

---

# 2. Brand Meaning

기존의 NAgex는 다음과 같은 의미에서 출발했다.

> Next-generation Agent Experience

그러나 NAgex의 제품 방향이 Agent 중심에서 Personal AI 중심으로 전환되면서, 브랜드 역시 더 넓고 장기적인 의미를 가져야 한다.

새로운 브랜드 해석은 다음과 같다.

> **NAgex = The Experience of the Next Age**

또는 더 간결하게:

> **NAgex = Personal AI for the Next Age**

이제 NAgex는 특정 기술 용어인 “Agent”에 종속되지 않는다.

Agent는 여전히 내부 아키텍처에서 중요한 실행 단위로 존재하지만, 사용자가 경험하는 제품의 정체성은 하나의 Personal AI다.

---

# 3. Core Brand Statement

## Canonical Brand Statement

> **NAgex is a Personal AI for the Next Age.**

NAgex는 사용자의 의도와 맥락을 이해하고, 기억하며, 필요한 일을 계획하고 실행하며, 장시간에 걸쳐 지속적으로 함께 일하는 Personal AI다.

---

# 4. Brand Promise

## Primary Brand Promise

> **Intelligence for the Next Age.**

이 문장은 NAgex의 가장 장기적인 브랜드 메시지다.

이 문장은 특정 기술에 종속되지 않는다.

- Agent
- LLM
- Model
- Tool
- Workflow
- Computer Use

와 같은 현재의 기술 용어가 변해도 유지할 수 있다.

NAgex의 핵심 약속은 “어떤 기술을 쓰는가”가 아니라 “사용자에게 어떤 지능 경험을 제공하는가”이기 때문이다.

# 6. What NAgex Represents

NAgex는 다음의 전환을 상징한다.

## From application to presence

기존 소프트웨어:

```text
앱을 연다
→ 기능을 찾는다
→ 메뉴를 선택한다
→ 작업한다
```

NAgex:

```text
NAgex를 부른다
→ 말하거나 보여준다
→ NAgex가 이해한다
→ 필요한 일을 처리한다
```

## From tool selection to intent

기존 AI 시스템:

```text
어떤 Agent?
어떤 Tool?
어떤 Model?
어떤 Workflow?
```

NAgex:

```text
무엇을 원하는가?
```

NAgex가 내부적으로 적절한 능력을 선택한다.

## From session AI to persistent intelligence

기존 Chat AI:

```text
질문
→ 답변
→ 세션 종료
```

NAgex:

```text
이해
→ 기억
→ 행동
→ 기다림
→ 계속 진행
→ 다시 알림
```

NAgex는 단발성 대화가 아니라 시간에 걸쳐 지속되는 Personal AI를 지향한다.

# 7. Brand Philosophy

## 7.1 One AI

사용자에게는 하나의 NAgex가 존재한다.

여러 Agent를 골라 쓰는 경험을 기본으로 하지 않는다.

## 7.2 Agent is Infrastructure, Not Interface

Agent는 내부 구조다.

사용자는 Browser Agent, Calendar Agent, Email Agent 등을 선택하지 않는다.

예:

```text
사용자
"이 기사 읽고 핵심을 정리하고, 할 일이 있으면 알려줘."

NAgex 내부
Browser Agent
→ Model Router
→ Memory
→ Task Candidate
→ Result
```

사용자에게는 이 전체가 “NAgex가 처리했다”로 보인다.

## 7.3 Human-Controlled Autonomy

NAgex는 스스로 판단하고 행동할 수 있어야 하지만, 중요한 결정은 사용자 통제 아래 있어야 한다.

핵심 원칙:

> **Autonomy without losing control.**

NAgex는:
- 행동한다.
- 그러나 중요한 외부 행동은 승인받는다.
- 사용자가 무엇을 했는지 확인할 수 있다.
- 가능한 경우 되돌릴 수 있다.

## 7.4 Personal Context

NAgex는 사용자를 매번 처음 만나는 AI가 아니다.

NAgex는:
- 선호
- 사람
- 프로젝트
- 중요한 사실
- 반복 업무
- 작업 방식

을 기억하고 다음 작업에 활용한다.

## 7.5 Continuity

NAgex는 하나의 대화창 안에서만 존재하지 않는다.

Desktop, Web, Mobile 등 여러 환경에서 동일한 Personal AI로 이어져야 한다.

# 11. Visual Brand Direction

브랜드가 “새 시대”를 말한다고 해서 SF 스타일로 만들지 않는다.

권장 방향:

- white / very light background
- NAgex blue accent
- dark navy typography
- large whitespace
- precise spacing
- restrained motion
- calm confidence
- premium editorial feeling

피해야 할 요소:

- neon
- glowing cards
- futuristic HUD
- excessive gradients
- excessive glassmorphism
- complex dashboard grids
- colorful agent icons

“Next Age”는 장식보다 문장, 여백, 타이포그래피, 제품 경험으로 전달한다.

# 12. Brand Voice

NAgex의 문체는:

- 짧고 명확하다.
- 과장하지 않는다.
- 기술을 자랑하기보다 결과를 설명한다.
- 사용자에게 시스템 구조를 공부시키지 않는다.
- 지나친 미래주의 표현을 피한다.

좋은 예:

```text
What would you like NAgex to handle?

Ask, talk, paste, or drop anything here.

NAgex is checking tomorrow's schedule.

This needs your attention.

Your report is ready.
```

피해야 할 예:

```text
Activate your autonomous multi-agent orchestration pipeline.

3 agents are currently executing 7 tool calls.

Select the optimal LLM provider.
```

# 16. Relationship to AGI

NAgex는 AGI를 보유하거나 달성했다고 주장하지 않는다.

브랜드는 특정 기술적 AGI 달성 주장을 기반으로 하지 않는다.

NAgex가 말하는 “Next Age”는 다음과 같은 제품 경험의 변화다.

```text
AI as a passive tool
→ AI as an active agent
→ AI as persistent, contextual, personal intelligence
```

따라서 브랜드 메시지는 기술적 과장을 피하고, 사용자의 실제 경험 변화에 기반한다.

# 18. Naming Rule Going Forward

새로운 기능명이나 서브제품이 추가되더라도 `Agent`를 무조건 이름에 붙이지 않는다.

예:

피해야 할 방식:

```text
NAgex Browser Agent
NAgex Calendar Agent
NAgex Email Agent
```

권장 사용자 표현:

```text
Browser
Calendar
Email
Connections
Tasks
Memory
Vault
```

Agent 이름은 내부 아키텍처 또는 개발자 문서에만 사용한다.

# 19. Brand Decision Rules

새로운 브랜드 문구나 UI를 만들 때 다음 질문을 확인한다.

1. NAgex가 하나의 Personal AI로 보이는가?
2. 특정 Agent 제품처럼 보이지 않는가?
3. 특정 LLM 하나에 종속되어 보이지 않는가?
4. 사용자가 내부 시스템을 이해해야 하는 문구인가?
5. 과장된 AGI/자율성 주장이 들어가 있지 않은가?
6. “Next Age”가 장식이 아니라 제품 철학과 연결되는가?
7. 3~5년 뒤에도 사용할 수 있는 표현인가?
